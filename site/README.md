# The Pool Table and the Orchard

An interactive companion to *Understanding Frequentist Inference – The orchard experiment*.

- `index.html`: the page and all explanatory text
- `styles.css`: layout and visual design
- `app.js`: the simulations and charts (plain JavaScript, no build step, no dependencies)

## View it

Open `index.html` in a browser. It works straight from disk; an internet connection is only needed for the web fonts, and the page falls back to system fonts without one.

## Publish it

Upload the three files to any static host. For GitHub Pages: put them in a repository, then under **Settings → Pages** choose the branch and folder that contain `index.html`.
